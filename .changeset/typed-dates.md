Dates can be typed: new DateInput (mm/dd/yyyy, slashes fill in), used by DatePicker and by DateRangePicker's Start and End boxes. Calendar captions: the month and the year open lists that scroll to the current one. Filters dialog: multi-select pills start all selected and Select all restores them; required groups show a red star. Report library: each tile's options button sits inside the tile.
