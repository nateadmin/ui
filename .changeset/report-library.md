New ToolbarReportLibrary: saved reports in categories for reports pages. Categories (add, rename, delete; reports from a deleted category move to Uncategorized), report tiles (open, rename, delete), Save as report with a name and a category, Update report with a confirmation and Save as new once the open report has unsaved changes. The catalog's Report page uses it, and each saved report restores the whole view.
